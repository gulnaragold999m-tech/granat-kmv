# GSAP без сборщика

Живой сайт «Граната» — это Flask: шаблоны Jinja и статика из
`zhivoj-sajt/static/`. Сборщика фронтенда в нём нет.
GSAP в такой стек ставится, и ставится просто, — но только тогда,
когда его действительно нужно.

## Когда GSAP оправдан

- **Таймлайн.** Пять элементов в заданном порядке, с перекрытием,
  с возможностью проиграть назад. На CSS это превращается в лес
  `transition-delay`, который никто потом не изменит.
- **ScrollTrigger.** Сцена, привязанная к положению прокрутки:
  элемент «приколот» и меняется, пока человек листает.
- **Плавная остановка и перехват.** Анимация, которую надо прервать
  на середине и увести в другое состояние без рывка.

## Когда не оправдан

Появление блоков, наведение, раскрытие меню, загрузчик. Всё это CSS
делает без единого килобайта. Библиотека ради появления карточек —
это лишний файл на каждой странице ради того, что и так работает.

## Как подключать

**Только локальным файлом, не с CDN.** Причина та же, по которой убрали
Google Fonts: обращение браузера посетителя на чужой сервер отдаёт туда
его IP и адрес страницы, а сайт собирает заявки по 152-ФЗ. Плюс
надёжность: чужой CDN может быть недоступен из России в любой момент.

1. Скачать `gsap.min.js` (и `ScrollTrigger.min.js`, если нужен) с
   официального сайта.
2. Положить в `zhivoj-sajt/static/js/vendor/`.
3. Подключить на **той странице, где он нужен**, а не в общей обвязке:

```html
<script src="/static/js/vendor/gsap.min.js" defer></script>
<script src="/static/js/vendor/ScrollTrigger.min.js" defer></script>
```

4. Не забыть загрузить папку в Amvera целиком — иначе на живом сайте
   скрипта не будет, а в репозитории он будет.
5. Посмотреть, во что это обошлось по весу — до того, как радоваться:

```
gzip -c zhivoj-sajt/static/js/vendor/gsap.min.js | wc -c
```

Порядок величины у ядра — десятки килобайт в сжатом виде, ScrollTrigger
примерно вдвое легче. **Точное число берётся этой командой, а не из
статьи в интернете:** версии меняются.

## Скелет сцены

```js
if (!window.gsap) return;                       // файл не доехал — страница живёт дальше
const tiho = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
if (tiho) return;                               // движение выключено — ничего не делаем

gsap.registerPlugin(ScrollTrigger);

const tl = gsap.timeline({
  scrollTrigger: {
    trigger: '.scena',
    start: 'top 70%',
    once: true,          // один раз за визит, а не при каждом проходе
  },
  defaults: { duration: .4, ease: 'power3.out' },
});

tl.from('.scena-zagolovok', { y: 20, opacity: 0 })
  .from('.scena-karta',     { y: 16, opacity: 0, stagger: .07 }, '-=0.2');
```

Что здесь важно и повторяется в каждой сцене:

- **Проверка `window.gsap`.** Скрипт не доехал — страница обязана
  работать без него. Это то же правило, по которому собранные страницы
  лежат в репозитории: сломалось одно — сайт не падает целиком.
- **Проверка `prefers-reduced-motion` в JS.** CSS-глушение до
  скриптовой анимации не достаёт.
- **`once: true`.** Иначе блок оживает при каждом проходе мимо, и
  на длинной странице это утомляет к третьему экрану.
- **`.from`, а не `.to`.** Элемент уже стоит на своём месте в разметке;
  анимация приводит его оттуда, а не уводит туда. Если JS не выполнился,
  всё видно.

## Пиннинг — осторожно

`pin: true` перехватывает прокрутку. На телефоне это самое частое место,
где сайт «залипает»: человек листает, а страница не двигается, и он
уходит. Правило: **пиннинг только на десктопе**, на телефоне сцена
показывается обычным появлением.

```js
ScrollTrigger.matchMedia({
  '(min-width: 1024px)': () => { /* сцена с пиннингом */ },
});
```

## Лицензия

GreenSock после покупки Webflow объявил GSAP бесплатным целиком,
включая плагины, — это написано в их официальном репозитории
`greensock/gsap-skills` (проверено 18.08.2026). **Клиенту это
пересказывать только после проверки на `gsap.com` в день разговора:**
лицензии меняются, а обещание остаётся в договоре.
