# Откуда взят этот навык

`zanwei/design-dna`, лицензия MIT (файл `LICENSE` рядом).
Взято 18.08.2026, версия `9d9d795` от 13.04.2026.
`SKILL.md` и `references/` — авторские, слово в слово.
Не перенесены только переводы README на пять языков и картинка-пример.

**Он на английском и работает по-своему:** раскладывает референс
в подробный JSON по трём измерениям — токены, качественный стиль,
визуальные эффекты — и умеет генерировать по этому JSON новый макет.

**Наш навык рядом называется `dizajn-dnk`** и решает ту же задачу
короче и под наш стек: шесть слоёв, токены в `site.css`, скрипт
проверки, разговор с заказчиком по-русски.

Порядок такой: работаем по `dizajn-dnk`; открываем `design-dna`, когда
нужна подробная схема разбора или когда референсов много и нужен
машиночитаемый профиль, который потом сверять между страницами.

Обновлять — заново скачивая репозиторий, а не правя файлы здесь:
правки в чужом навыке потеряются при следующем обновлении.
