# Библиотека решений: стили, палитры, шрифты, правила UX

Веб-часть открытого набора `genjutsu`, положенная в проект. Ценность
в одном: **это таблицы, по которым можно искать**, а не рассуждения.
Когда нужно быстро предложить заказчику три варианта стиля с палитрами
и шрифтами — здесь они есть, с пометками про доступность и
производительность.

**Наш порядок остаётся прежним:** `dizajn-dnk` снимает ДНК с референса,
`vizualnyj-vkus` доводит и принимает работу. Этот навык — источник
вариантов, когда референса нет или он один и слабый.

## Как искать

Поиск идёт по таблицам, лежащим рядом. Интернет не нужен.

```
python3 .claude/skills/genjutsu-vkus/_jutsu/ui-ux-pro-max/scripts/search.py "тёмный неон, техно" --domain style --max-results 3
```

Разделы (`--domain`): `style` — стили интерфейса, `color` — палитры,
`typography` — шрифтовые пары, `ux` — правила, `landing` — блоки
посадочных, `chart` — типы графиков, `icons` — наборы иконок,
`product` — решения под тип продукта, `motion`, `gsap`, `react`, `web`.

Запрос можно писать по-русски, но **таблицы английские** — по-английски
находится больше. Полезно и `--stack html-tailwind`, если нужна
привязка к стеку.

## Что ещё лежит внутри

| Папка | Про что |
|---|---|
| `_jutsu/ui-ux-pro-max/` | сам датасет: стили, палитры, шрифты, правила UX, посадочные, графики |
| `_jutsu/design-audit/` | аудит интерфейса по пунктам — чем придираться по делу |
| `_jutsu/motion-principles/` | принципы движения: характер, вес, хореография |
| `_jutsu/css-native/` | что современный CSS умеет сам, без библиотек |
| `_jutsu/canvas-generative/` | генеративная графика на canvas — наш случай для частиц |
| `_jutsu/desktop-principles/`, `_jutsu/mobile-principles/` | различия десктопа и телефона |
| `references/cast-orkestrator.md`, `paint-orkestrator.md` | их порядок работы: как автор ведёт задачу от разбора стека до полировки |

**Чего не взяли:** SwiftUI, Jetpack Compose, Compose Multiplatform,
Framer Motion и React Three Fiber. Мы не делаем мобильные приложения
и не используем React — эти папки были бы мёртвым грузом.

## Три поправки, обязательные для нас

1. **Шрифтовые пары даются ссылками на Google Fonts.** У нас так нельзя:
   шрифты самохостятся рядом со стилями сайта, иначе IP посетителя
   уезжает за границу, а сайт собирает заявки по 152-ФЗ. Берём имена
   гарнитур, файлы скачиваем и кладём к себе.
2. **Кириллица проверяется до показа заказчику.** Половина красивых
   пар из таблицы — латиница без кириллицы. Красивый заголовок,
   который нельзя написать по-русски, стоит дороже, чем кажется:
   его показали, он понравился, и теперь его нет.
3. **Пометки «Accessibility: Limited» читать буквально.** Контраст
   проверяем числом, а не глазом: клиент смотрит с телефона, часто
   недорогого и на солнце.
4. **Сайт типографии не выбирает стиль с нуля** — фирменный стиль уже
   существует, он в `firmennyj-stil/`, и на бумаге его видно раньше,
   чем на экране. Из таблиц берём приёмы и правила UX, а не новую
   палитру взамен своей.

## Источник

`AThevon/genjutsu`, лицензия MIT (файл `LICENSE` рядом). Взято
18.08.2026, версия `08a792f` (релиз v3.3.0) от 31.07.2026. Файлы
внутри `_jutsu/` и `references/` — авторские, слово в слово.

**Целиком набор — это плагин Claude Code** с двумя своими режимами
работы (`/genjutsu:cast` — оживить готовый интерфейс, `/genjutsu:paint` —
собрать визуальную систему с нуля). Ставится в Claude Code двумя
командами: `/plugin marketplace add AThevon/genjutsu`, затем
`/plugin install genjutsu`. Здесь лежит его знание, а не сам плагин:
плагин живёт в настройках программы и в репозиторий не кладётся.

Обновлять — заново скачивая репозиторий, а не правя файлы здесь.
