# GSAP: справочник в проекте

Официальный набор навыков GreenSock, положенный к нам целиком, чтобы
API не приходилось вспоминать. Память врёт в мелочах — в порядке
аргументов, в имени свойства, — а такая ошибка стоит получаса.

**Порядок работы: сначала `animacii-veb`, потом этот навык.**
Первый решает, нужна ли здесь библиотека вообще и укладывается ли
задумка в тайминги и в `prefers-reduced-motion`. Этот — как написать
то, что решено. Наоборот не работает: справочник с удовольствием
поможет собрать сцену, которая не нужна.

## Чего здесь нет и почему

Из восьми навыков набора не взяты два: `gsap-react` и `gsap-frameworks`
(Vue, Svelte, Nuxt). **В проекте нет ни React, ни сборщика**, и правило
`CLAUDE.md` прямо запрещает их подключать без необходимости. Понадобятся —
берутся из первоисточника, ссылка ниже.

## Наши поправки к их советам

Справочник писали для мира, где фронтенд собирается сборщиком и
раздаётся с CDN. У нас иначе, и три вещи придётся делать по-своему:

1. **Подключение — локальным файлом, не с CDN и не через npm.**
   `zhivoj-sajt/static/js/vendor/gsap.min.js`, скрипт с `defer`, только
   на той странице, где нужен. Причина — та же, по которой убрали
   Google Fonts: IP посетителя не должен уезжать на чужой сервер.
2. **Любая сцена начинается с двух проверок** — `window.gsap`
   существует и `matchMedia('(prefers-reduced-motion: reduce)')`
   не сработал. Готовый скелет —
   `../animacii-veb/references/gsap-bez-sborshchika.md`.
3. **Пиннинг только на десктопе.** На телефоне перехваченная прокрутка
   читается как зависший сайт.

## Источник

`greensock/gsap-skills`, официальный репозиторий GreenSock, лицензия MIT
(файл `LICENSE` рядом). Взято 18.08.2026, версия `aed9cfd` от 21.04.2026.
Файлы в `references/` — их, слово в слово; переименованы только имена
файлов. Обновлять — оттуда же, заново скачивая репозиторий.

**Про «GSAP теперь бесплатен целиком, включая плагины»:** так написано
в их README после покупки GreenSock компанией Webflow. Клиенту это
повторять только после проверки на `gsap.com` в день разговора —
лицензии меняются, а обещание остаётся в договоре.
