# Three.js: справочник в проекте

Набор из десяти файлов по разделам Three.js, положенный к нам целиком.
Нужен по одной причине: **API Three.js меняется от релиза к релизу**,
и код, написанный по памяти или по статье трёхлетней давности,
не запускается — а ошибка выглядит как «не работает 3D».

**Порядок работы: сначала `3d-na-sajte`, потом этот навык.**
Первый отвечает на вопрос, нужен ли здесь 3D вообще (для лендинга
местного бизнеса почти всегда нет), задаёт бюджет по весу, запасную
картинку и отключение на слабых телефонах. Этот — как написать сцену,
когда решение уже принято.

## Наши поправки к их советам

Справочник исходит из того, что проект собирается сборщиком и ставит
Three.js через npm. У нас статические файлы, поэтому:

1. **Подключение — через `importmap` с локальными файлами**
   в `zhivoj-sajt/static/js/vendor/`, не через npm и не с CDN. Готовый
   скелет со всеми проверками — `../3d-na-sajte/references/minimalnaya-scena.md`.
2. **Постобработка и тени по умолчанию выключены.** В справочнике
   это отдельные разделы, у нас — первое, что снимается ради телефона.
3. **Плотность пикселей ограничена двойкой**, размер холста —
   не на весь экран. Это даёт больше, чем все остальные оптимизации
   вместе взятые.
4. **Сцена обязана уметь не запускаться**: нет WebGL, включено
   «уменьшить движение», экономия трафика, слабое устройство —
   показывается картинка.
