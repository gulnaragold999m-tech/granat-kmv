# Чек-лист приёмки страницы

Проходится **до** показа заказчику. Занимает пятнадцать минут и
экономит круг правок, потому что половину замечаний заказчик просто
не успевает сделать — они уже исправлены.

## 1. Смысл

- [ ] Первый экран отвечает на три вопроса: что это, для кого, что делать дальше
- [ ] На экране одно главное действие, и оно единственное окрашено акцентом
- [ ] Ни одного обещания, которого мы не выполняем
- [ ] Цены и сроки совпадают с прайсом (`npm run ceny`), а не написаны руками
- [ ] Телефон, почта и адрес — те, что в правилах проекта

## 2. Текст

- [ ] Прочитан вслух целиком; там, где сбился язык, — переписано
- [ ] Нет воды и превосходных степеней («лучшие», «динамично развивающаяся»)
- [ ] Термины объяснены одним предложением
- [ ] Кавычки-ёлочки, длинное тире, неразрывные пробелы в числах, ё

## 3. Вид

- [ ] Гарнитур не больше трёх, кеглей не больше шести
- [ ] Отступы кратны базовому шагу
- [ ] Длина строки 45–75 знаков
- [ ] Контраст текста не ниже 4,5:1
- [ ] Иконки из одного набора, одной толщины
- [ ] Фотографии одной обработки, стока с рукопожатиями нет

## 4. Поведение

- [ ] У кнопок: покой, наведение, нажатие, видимый фокус
- [ ] У формы: пустая, отправляется, отправлена, не отправлена
- [ ] У списков: пусто, грузится, ошибка
- [ ] Движение выключается при «уменьшить движение»
      (`node .claude/skills/animacii-veb/scripts/proverka-dvizheniya.mjs zhivoj-sajt`)

## 5. Телефон

- [ ] Открыто на настоящем телефоне, не в узком окне браузера
- [ ] Ширина 320 px — ничего не вылезает
- [ ] Кегль основного текста не меньше 16 px
- [ ] По кнопкам попадает палец: не меньше 44×44 px
- [ ] Длинный заголовок в две строки сетку не ломает

## 6. Механика

- [ ] Стили Tailwind пересобраны, папки загружены в Amvera целиком
- [ ] `node .claude/skills/dizajn-dnk/scripts/proverka-tokenov.mjs zhivoj-sajt` — чисто
- [ ] У картинок `alt`, у полей `label`, у страницы `title` и описание
- [ ] Страница открывается на `granat-kmv.ru` после обновления Ctrl+F5

## Как показывать заказчику

**Ссылкой на живую страницу, открытой с телефона.** Не скриншотами:
скриншот обсуждают как картинку, живую страницу — как сайт.

Вопрос задавать закрытый: «принимаем в таком виде?». Открытое
«как вам?» превращает приёмку в поиск замечаний — и находятся они
всегда, потому что искать просили.

Если замечания есть, записывать их **списком с номерами** и повторять
вслух, прежде чем править: половина замечаний при повторе отпадает
сама, а оставшиеся становятся точнее.
