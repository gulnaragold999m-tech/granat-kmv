# Гранат — Типография и веб-студия

Сайт студии «Гранат» на Next.js: печать и полиграфия, сайты и боты.
Живой адрес — https://granat-kmv.ru

## Структура проекта

```
app/
├── layout.tsx            # шапка, меню, подвал — общие для всех страниц
├── page.tsx              # Главная
├── pechat/page.tsx       # Печать и полиграфия — весь прайс
├── cifra/page.tsx        # Сайты и боты
├── kontakty/page.tsx     # Контакты и форма заявки
├── FormWithConsent.tsx   # форма с согласием на обработку ПДн
└── api/
    ├── lead/route.ts     # приём заявки, отправка письмом
    └── price/route.ts    # прайс текстом и JSON — для бота
data/prices.ts            # ЕДИНЫЙ ПРАЙС — источник правды
scripts/ceny.mts          # npm run ceny — прайс списком в окно
public/                   # robots.txt, sitemap.xml, картинки
```

**Файлы `layout.tsx`, `page.tsx` и `globals.css` лежали в корне
и не работали.** Next читает страницы только из папки `app/`, поэтому
до 15.08.2026 на сайте не было ни главной страницы, ни меню, ни подвала:
собирались только `/pechat`, `/cifra` и `/kontakty`, а корень отдавал 404.
15.08.2026 файлы перенесены в `app/`, главная появилась. Проверяется
одной командой — `npm run build` печатает список адресов, и `/` обязан
быть в этом списке.

## Цена живёт в одном месте — `data/prices.ts`

Прайс перенесён из печатного прайс-листа от 09.08.2026, **все десять
страниц**. Правим цену только там. Оттуда её берут:

| Кто | Как |
|---|---|
| Страница «Печать и полиграфия» | `app/pechat/page.tsx` строит таблицы из прайса |
| Главная | четыре цены на первом экране считаются из тех же таблиц |
| Бот | забирает по адресу `/api/price` |
| Окно на компьютере | `npm run ceny` |

Посмотреть весь прайс списком, не открывая код:

```bash
npm run ceny
```

**Чего в прайсе нет — того нет и на сайте.** Визитки, сертификаты,
стикеры, фирменный стиль, тиснение золотом: до 15.08.2026 они висели
на сайте с выдуманными ценами вроде «визитки 200–500 ₽», хотя
в печатном прайсе таких позиций нет вообще. Убраны. Появится цена
в прайсе — вернутся на сайт. Список — `NET_V_PRAJSE` в конце
`data/prices.ts`.

## Прайс для бота — `/api/price`

Бот студии живёт отдельным приложением на Amvera. Чтобы его прайс
не разошёлся с сайтом, бот не хранит цены у себя, а забирает их:

```
https://granat-kmv.ru/api/price              прайс текстом, прямо в промпт
https://granat-kmv.ru/api/price?format=json  то же самое по разделам
```

Правим `data/prices.ts`, выкатываем — и у бота новая цена без правки бота.

## Заявки с формы уходят письмом

До 15.08.2026 обработчик формы писал заявку в лог и отвечал «Заявка
получена». Человек видел «свяжемся в течение часа», а заявка не уходила
никуда. Теперь заявка уходит письмом на почту, а если почта не настроена —
форма честно пишет «заявка не ушла, позвоните» и даёт телефон.

**Чтобы заявки приходили, в Amvera нужны три переменные окружения:**
`MAIL_TO`, `SMTP_USER`, `SMTP_PASS` — см. `.env.example`. `SMTP_PASS` —
это пароль приложения из Яндекса, а не пароль от почты. Завели
переменные — нажмите «Перезапустить»: Amvera читает их только при старте.

## Telegram снят с сайта 15.08.2026

Решение владелицы: Telegram больше не канал для заявок. С сайта убраны
ссылки на `@GranatJarvis_bot` — из подвала и со страницы контактов.
Остались телефон, WhatsApp, почта и форма.

Это не отменяет **разработку ботов как услугу** — она на месте,
на странице `/cifra`.

## Чего на сайте ещё нет

- **Страниц `/privacy` и `/consent` не существует**, а форма на них
  ссылается и собирает персональные данные. Это нарушение 152-ФЗ,
  и его надо закрыть до рекламы.
- **Страниц `/portfolio` и `/o-nas` нет** — ссылки на них убраны
  из меню и из `sitemap.xml`, чтобы не отдавать поисковикам 404.

## Стек

- **Frontend:** React 19, Next.js, Tailwind CSS
- **Хостинг:** Amvera
- **Язык:** TypeScript

## Установка

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000

## Переменные окружения

Скопируй `.env.example` в `.env.local` и заполни токены:

```bash
cp .env.example .env.local
```

⚠️ **ВАЖНО:** Никогда не коммить `.env.local` с токенами! Используй `.env.example` как шаблон.

## Деплой на Amvera

1. Создай аккаунт на https://amvera.ru
2. Подключи GitHub репо
3. Выбери ветку main
4. Укажи команду запуска: `npm install && npm run build && npm start`
5. Добавь переменные окружения в Amvera

## Команды

- `npm run dev` — разработка
- `npm run build` — сборка для продакшена
- `npm start` — запуск продакшена
- `npm run lint` — проверка кода
