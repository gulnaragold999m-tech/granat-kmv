# Гранат — Типография и веб-студия

Многостраничный сайт студии Гранат на Next.js с поддержкой печати, сайтов и Telegram-ботов.

## Структура проекта

```
app/
├── page.tsx              # Главная
├── pechat/page.tsx       # Печать и полиграфия
├── cifra/page.tsx        # Сайты и боты
├── portfolio/page.tsx    # Портфолио
├── o-nas/page.tsx        # О студии
├── kontakty/page.tsx     # Контакты и форма
└── layout.tsx            # Главный лейаут с навигацией
```

## Цена живёт в одном месте — `data/prices.ts`

Прайс студии перенесён из печатного прайс-листа от 09.08.2026 и лежит
в одном файле. Правим цену только там: оттуда её берут страницы сайта,
бот и рекламные макеты. Записанная руками во второй раз цена рано или
поздно разъезжается.

Посмотреть весь прайс списком, не открывая код:

```bash
npm run ceny
```

**Перенесены страницы 1–5 из 10:** фото на документы, печать фотографий,
ксерокопия и распечатка, флаеры и листовки, евробуклет, открытки
и приглашения. Страниц 6–10 у нас пока нет — что именно отсутствует,
перечислено в конце `data/prices.ts`, список `NE_PERENESENO`.

**Страница `app/pechat/page.tsx` показывает другие цены** — визитки,
сертификаты, стикеры, фирменный стиль. В печатном прайсе таких позиций
нет. Страницу надо пересобрать из `data/prices.ts`, когда появятся
недостающие страницы прайса.

## Стек

- **Frontend:** React 19, Next.js, Tailwind CSS
- **Хостинг:** Amvera
- **Язык:** TypeScript

## Установка

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000

## Переменные окружения

Скопируй `.env.example` в `.env.local` и заполни токены:

```bash
cp .env.example .env.local
```

⚠️ **ВАЖНО:** Никогда не коммить `.env.local` с токенами! Используй `.env.example` как шаблон.

## Деплой на Amvera

1. Создай аккаунт на https://amvera.ru
2. Подключи GitHub репо
3. Выбери ветку main
4. Укажи команду запуска: `npm install && npm run build && npm start`
5. Добавь переменные окружения в Amvera

## Команды

- `npm run dev` — разработка
- `npm run build` — сборка для продакшена
- `npm start` — запуск продакшена
- `npm run lint` — проверка кода
