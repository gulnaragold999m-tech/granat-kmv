# QR-коды на заявку

Ведут на `granat-kmv.ru/z` — короткий адрес, который открывает сразу
форму заявки, а не главную. С меткой `utm_source=qr`, поэтому в Метрике
видно отдельно, сколько людей пришло с печати.

**Куда ставить, по убыванию отдачи:**

| Где | Почему сработает |
|---|---|
| На чеке или бланке заказа | человек уже клиент, вернётся за повтором |
| На упаковке готового тиража | пакет с визитками показывают коллегам |
| На двери студии и на стойке | зашёл, увидел цену, ушёл думать — навёл камеру |
| В прайсе, который отдаёте на руки | там же, где цена |
| На визитке студии | |

**Что говорить клиенту:** «Наведите камеру — откроется форма, там
можно приложить макет». Не «отсканируйте QR-код»: половина людей
не понимает, что это.

Печатать не мельче 2×2 см, иначе камера телефона не поймает. Код сделан
с высокой устойчивостью — читается, даже если угол смят или заляпан.
