## Ограничения — проверить перед публикацией

- [ ] Услуги и цены только из `data/prices.ts`.
- [ ] Срок не обещан сверх того, что умеет калькулятор.
- [ ] Срочность записана как «сегодня, день в день — +30%».
- [ ] Предоплата — 30%.
- [ ] Нет услуг из `NET_V_PRAJSE`: фирменного стиля, тиснения, конгрева,
      УФ-лака, контурной резки наклеек, съёмки на документы.
- [ ] Нет обещаний позиций в поиске и штрафов «до 700 000 ₽».
- [ ] Скидка названа только если она есть в `AKCII` и активна.

Прогнать скрипт:

```
npm run proverka tasks/market-research/<этот-файл>.md
```
